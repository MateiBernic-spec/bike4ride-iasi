# Bike 4 Ride Iași — site de prezentare

Site de prezentare **neoficial** pentru magazinul și service-ul de biciclete Bike 4 Ride (Strada Sfântul Lazăr nr. 55, Iași): locație, program, servicii și prețuri orientative.

Construit cu **React 18**, **GSAP + ScrollTrigger** și **Lenis** (smooth scroll), într-un singur fișier `index.html`, fără build.

- Prețurile sunt intervale orientative din piața de service biciclete din România; magazinul nu publică o listă oficială.
- Fotografii: Wikimedia Commons (licențe libere, autorii sunt menționați în subsolul site-ului).

Rulare locală: deschide `index.html` în browser.
